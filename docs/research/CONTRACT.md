# 股票投研系统（Stock Research System）调研契约与质量标准

> 调研基准时间：**2026 年**（重点覆盖 2024–2026 年最新演进与当前最主流落地实践）。
> 所有调研结论将直接作为本产品立项、技术选型与开发计划拍板的依据。

## 1. 调研目标与覆盖市场
- **目标市场**：同时关注 **A股（核心关注）、美股（成熟范式与工具链最丰富）、港股（次要/联动）**，并明确区分不同市场在数据源、信息形态、交易机制和合规上的差异。
- **核心命题**：在 AI Agent 与大模型快速演进的背景下，打造一款既具备专业金融数据准确度、又能显著提升投研效率的现代化股票投研系统，市面上最新和最主流的产品形态与工程架构到底是什么？哪些已被验证有效，哪些只是 Demo 噱头？

## 2. 强制质量标准（Evidence-First）
1. **必须基于实时联网检索验证**：优先查阅官方文档、GitHub 仓库最新状态（Star/活跃度/架构变化）、产品官网定价与功能页、权威工程博客。严禁仅凭旧记忆编造项目名、API 定价或版本号；如某个信息无法核实，必须明确标注 `[待核实]`。
2. **区分“生产级主流方案”与“玩具/Demo 方案”**：不要把 GitHub 热门 Demo 直接当成可上线方案，要客观指出其在数据一致性、成本、幻觉率、延迟、合规上的真实短板。
3. **结构化对比优先**：凡涉及竞品、开源框架、数据源、模型与数据库选型，必须给出清晰的 Markdown 对比表（含核心能力、覆盖市场、成本/协议、优势、致命短板、适用阶段）。
4. **中文撰写，专业术语保留英文原名**：如 Multi-Agent、MCP、Text-to-SQL、Citation Grounding、Point-in-Time (PIT) 数据等。
5. **输出面向产品决策的 actionable 建议**：每份报告结尾必须给出「对我们自研系统的核心启示（Must-Have / Should-Have / Anti-Patterns 避坑清单）」。
